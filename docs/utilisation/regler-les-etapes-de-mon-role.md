# Comment régler les étapes de mon rôle ?

Pour un titulaire d'un rôle qui reçoit des demandes, ou pour qui gère les rôles.

1. Ouvrez **Caserne**, puis **Faire une demande**, puis votre rôle sous **Demandes reçues**. (Qui gère les rôles peut aussi passer par **Réglages**, **Rôles**, la page du rôle, bloc **Demandes**.)
2. Ouvrez **Régler les étapes**.
3. Pour ajouter une étape, écrivez son nom dans **Nouvelle étape** (par exemple « Commandée »), puis appuyez sur **Ajouter l'étape**. Six étapes au plus.
4. Pour renommer, changez le nom, puis appuyez sur **Enregistrer les étapes**. La dernière étape se renomme de même (par exemple « Livrée »).
5. Pour changer l'ordre, appuyez sur **Monter** ou **Descendre** ; pour en enlever une, sur **Retirer**.

Une étape où se trouve une demande en cours ne se retire pas : avancez ou finissez d'abord cette demande. Seul qui gère les rôles coche ou décoche **Reçoit des demandes**.
